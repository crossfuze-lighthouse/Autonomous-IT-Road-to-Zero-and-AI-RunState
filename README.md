# Crossfuze AI Readiness Assessment guide

Static site for GitHub Pages.

| File | What it is |
|---|---|
| `index.html` | The guide (17 pages). Opens as the site's home page. |
| `Crossfuze-AI-Readiness-Assessment-Guide.pdf` | PDF of the guide, served by the **Download PDF** button on `index.html`. |

## Publish
1. Upload all files in this folder to the root of the repository (keep the file names exactly as they are; the Download PDF button links to the PDF by name).
2. In the repository, go to **Settings → Pages**, set the source to the `main` branch and the root folder, and save.
3. The guide is then live at `https://<org>.github.io/<repo>/`.

All images and fonts are embedded, so no other files are needed.
